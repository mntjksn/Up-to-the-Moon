# Up-to-the-Moon (하늘로 올라라!!)

Unity 기반으로 개발한 2D 방치형 모바일 게임입니다.  
개인 프로젝트로 진행했으며, 자원 수급 구조와 캐릭터 강화 시스템을 중심으로 개발했습니다.

---

## 🎮 프로젝트 개요
- 장르: 2D 방치형 성장 게임  
- 개발 인원: 개인 프로젝트
- 개발 도구: Unity, C#  
- 플랫폼: Android
  
---

## 🛠 기술 스택
- Engine: Unity  
- Language: C#  
- Data: JSON  
- Platform: Android
  
---

## ⚙️ 주요 구현 기능
- 상태 기반 캐릭터 성장 시스템- 골드 및 보상 획득 로직
  - Step 단위 업그레이드 설계로 능력치 변화와 상태 전이를 관리
  - 중앙 데이터 기준으로 로직 일관성 유지
- 자원 수급 및 보상 파이프라인
  - 드롭 → 반영 → 저장 흐름을 단일 경로로 처리
  - 반복 발생 로직에서도 안정적으로 동작하도록 설계
- 데이터 중심 콘텐츠 구조
  - JSON 기반 정의 데이터와 런타임 상태 데이터 분리
  - 콘텐츠 수정 시 코드 변경 없이 확장 가능하도록 구성
- 이벤트 기반 UI 반응 시스템
  - 상태 변경 이벤트를 구독하여 부분 UI만 갱신
  - 성능 부담을 줄이고 유지보수성을 확보

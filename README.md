# Up-to-the-Moon (하늘로 올라라!!)
Unity 기반 2D 방치형 모바일 게임입니다.  
플레이어는 자동 비행으로 하늘을 상승하며 자원을 수집하고, 수집한 자원으로 캐릭터를 업그레이드해 더 높은 목표 지점에 도달하는 구조로 설계했습니다.

## 프로젝트 개요
- 개발 환경 : Unity 2D
- 사용 언어 : C#
- 개발 기간 : 2025.12 ~ 2026.01
- 개발 인원 : 1인 (개인 프로젝트)
- 플랫폼 : Android (Mobile)

## 주요 기능
- 자동 비행 시스템 — 캐릭터가 자동으로 상승하며 목표 거리까지 진행
- 자원 수집 / 판매 시스템 — 진행 거리에 따라 해금되는 자원을 수집하고 골드로 전환
- 성장 업그레이드 시스템 — 이동 속도, 수집 효율, 저장 용량 업그레이드
- 지역 / 도감 해금 — 거리 진행도에 따라 배경과 수집 정보 해금

## 기술적 고민
### 1. Android 실기기 화면 멈춤 및 재생성 문제 해결
- 에디터에서는 정상 동작했지만, Android 실기기 테스트 중 화면이 멈추거나 다시 초기화되는 현상이 간헐적으로 발생했습니다.
- 처음에는 게임 로직 문제로 접근했지만, logcat을 통해 surfaceDestroyed, surfaceCreated 로그가 반복 발생하는 것을 확인하면서 Activity 재생성이 원인임을 파악했습니다.
- AndroidManifest에 configChanges 옵션을 추가해 화면 회전 및 크기 변경에 의한 Activity 재생성을 방지하도록 수정했습니다.
- 그 결과 화면 재생성 및 멈춤 현상이 완화됐고, 로그 기반으로 플랫폼 이슈를 추적하고 대응하는 흐름을 경험했습니다.

## 회고
### 주요 어려움
  #### 1. 에디터와 실기기 동작 차이
  - 에디터에서는 발생하지 않던 문제가 실기기에서만 재현되어 원인을 찾는 데 시간이 걸렸습니다.
  - 게임 로직부터 점검했지만 logcat 분석을 통해 Android 플랫폼 생명주기 문제로 원인을 좁혀갈 수 있었습니다.
### 배운 점
- 모바일 개발에서는 에디터 테스트만으로는 확인할 수 없는 플랫폼 이슈가 존재한다는 것을 배웠습니다.
- logcat을 활용한 로그 분석이 실기기 문제를 추적하는 데 효과적이라는 것을 경험했습니다.
- AndroidManifest 설정과 Android Activity 생명주기가 Unity 게임 실행에 직접적인 영향을 줄 수 있다는 점을 배웠습니다.



Unity 기반으로 개발한 2D 방치형 모바일 게임입니다.

## ⚙️ 주요 구현 기능
- **상태 기반 캐릭터 성장 시스템- 골드 및 보상 획득 로직**
  - Step 단위 업그레이드 설계로 능력치 변화와 상태 전이를 관리
  - 중앙 데이터 기준으로 로직 일관성 유지
- **자원 수급 및 보상 파이프라인**
  - 드롭 → 반영 → 저장 흐름을 단일 경로로 처리
  - 반복 발생 로직에서도 안정적으로 동작하도록 설계
- **데이터 중심 콘텐츠 구조**
  - JSON 기반 정의 데이터와 런타임 상태 데이터 분리
  - 콘텐츠 수정 시 코드 변경 없이 확장 가능하도록 구성
- **이벤트 기반 UI 반응 시스템**
  - 상태 변경 이벤트를 구독하여 부분 UI만 갱신
  - 성능 부담을 줄이고 유지보수성을 확보

# Up-to-the-Moon (하늘로 올라라!!)
플레이어는 자동 비행을 통해 하늘을 상승하며 자원을 수집하고, 수집한 자원을 사용해 캐릭터의 이동 속도와 수집 효율을 업그레이드할 수 있습니다.
반복 플레이를 통해 점진적으로 성장하고 더 높은 목표 지점에 도달하는 구조로 설계했습니다.

## 프로젝트 개요
- 개발 환경 : Unity 2D
- 사용 언어 : C#
- 개발 기간 : 2025년 12월 ~ 2026년 01월
- 개발 인원 : 1인 (개인 프로젝트)
- 플랫폼 : Android (Mobile)

## 주요 기능
- 캐릭터 합성 및 성장 시스템 (Merge) — 같은 캐릭터를 합성해 상위 캐릭터로 성장
- 미니게임 / 보스 콘텐츠 — 추가 재화 획득 및 성장 콘텐츠
- JSON 기반 게임 데이터 저장 및 복원 — 앱 종료 후 재실행 시 이전 상태 유지

## 기술적 고민
### JSON 기반 캐릭터 배치 데이터 저장 및 복원 시스템
- 캐릭터의 생성 여부, 위치, 레벨 정보를 저장하기 위해 JSON 기반 저장 구조를 구현했습니다.
- 게임 종료 후 다시 실행해도 배치된 캐릭터 상태가 유지되도록 저장 데이터와 게임 오브젝트 생성 로직을 연결했습니다.

## 회고
### 주요 어려움
 - 기존 방치형 게임 구조를 참고하면서, 캐릭터 성장, 저장 데이터, UI 갱신 흐름을 하나의 구조로 연결하는 부분이 어려웠습니다.
 - 캐릭터 배치 상태를 저장하고 복원하는 과정에서 게임 오브젝트와 저장 데이터가 어긋나지 않도록 관리하는 것이 중요했습니다.
### 배운 점
- Unity에서 JSON 데이터를 활용해 게임 상태를 저장하고 복원하는 흐름을 경험했습니다.
- 기능 구현 전에 데이터 구조와 오브젝트 생성 흐름을 먼저 정리하는 것이 유지보수와 기능 확장에 중요하다는 점을 배웠습니다.
